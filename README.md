# 청년일경험 팀지원금 정산 검토 시스템

청년일경험 사업에서 **팀별 지원금 사용에 대한 최종 비용 정산·결산을 검토**하는 웹 애플리케이션입니다.
팀별 지출 내역을 입력하면 항목 한도·증빙·예산 기준으로 자동 검증하고, 팀별 정산 결과와 보고서를 생성합니다.

## 주요 기능

- **📊 대시보드** — 전체 팀의 지원금·집행률·반납액·지적사항을 한눈에 확인
- **👥 팀 관리** — 참여 팀과 배정 지원금 등록
- **🏷️ 지출 항목 설정** — 항목별 한도 규칙 정의 (한도 없음 / 절대 금액 / 지원금 대비 비율 / 건당 단가)
- **🧾 지출 내역** — 직접 입력 또는 **엑셀 일괄 업로드/다운로드**
- **🔍 정산 검토** — 자동 검증
  - 지출 항목별 **한도 초과** 검증
  - 팀별 지원금 대비 **사용액·잔액·반납액** 집계
  - **증빙(영수증/계산서) 누락** 점검
  - 인정액 / 불인정액 구분
- **📄 정산 보고서** — 화면 보고서, **인쇄/PDF 저장**, **엑셀 보고서 내보내기**

## 검증 규칙

| 구분 | 내용 | 처리 |
|------|------|------|
| 증빙 누락 | 영수증/계산서 미첨부 | 오류 · 불인정액 처리 |
| 항목 한도 초과 | 항목 누적/비율 한도 초과 | 오류 |
| 총 지원금 초과 | 사용액 > 배정 지원금 | 오류 |
| 금액 오류 | 0원 이하 | 오류 · 불인정액 처리 |
| 건당 단가 초과 | 1건이 단가 한도 초과 | 경고 |
| 사용처 미기재 | 거래처 비어있음 | 경고 |

- **인정액** = 오류가 없는 지출 합계
- **반납액** = 배정 지원금 − 인정액

> ⚠️ 기본 항목/한도 값은 **예시**입니다. `지출 항목 설정`에서 실제 사업 운영지침에 맞게 조정하세요.

## 실행 방법

```bash
npm install      # 최초 1회
npm run dev      # 개발 서버 (http://localhost:5173)
npm run build    # 배포용 정적 파일 빌드 (dist/)
npm run preview  # 빌드 결과 미리보기
```

빌드 후 `dist/` 폴더를 정적 호스팅(Netlify, GitHub Pages 등)에 올리면 서버 없이 동작합니다.

## 엑셀 업로드 양식

`지출 내역 > 양식 다운로드`로 받은 엑셀의 컬럼:

| 팀명 | 항목 | 사용일 | 사용처 | 금액 | 내용 | 증빙여부 | 결제수단 |
|------|------|--------|--------|------|------|----------|----------|

- **팀명/항목**: 시스템에 등록된 이름과 정확히 일치해야 합니다 (양식의 `입력참고` 시트 참고)
- **증빙여부**: `O`, `Y`, `있음` 등이면 첨부로 인식
- **결제수단**: 카드 / 계좌이체 / 현금 / 기타

## 기술 스택 / 데이터

- **React + TypeScript + Vite**, 엑셀 입출력은 **SheetJS(xlsx)**
- 별도 서버·DB 없이 **브라우저 localStorage**에 저장 (개인정보·증빙 파일은 저장하지 않음)
- 데이터 백업은 `지출 내역 > 엑셀 내보내기` 활용
